# 🎯 NUMBER GUESSING GAME - FLASK WEB APPLICATION

Hello there and welcome!
What we have here is a simple and fun number guessing game built with Python Flask. The game generates
a random number between 0 and 9, and the player guesses it through the URL.


## GAME DESCRIPTION

1. A random number between 0 and 9 is generated when the server starts.

2. The playe guesses the number by adding their guess to the URL.

3. At the end, the result (whether the player wins or loses) is shown.

NOTE: The random number is generated when the Flask server starts. The same number
persists until the server is restarted.


## HOW TO RUN THE PROGRAM

- Install Flask: You can directly write "pip install flask" in the terminal or go to packages and find "flask" there

- Save the Code: Copy the code into a file (for example, "app.py" or any name you prefer with a .py extension)

- Run the Application: python app.py

- Access the Game: Open your web browser and go to: http://127.0.0.1:5000


## Solutions for Possible Troubleshooting

ISSUE: Flask not found
SOLUTION: Install Flask - pip install flask

ISSUE: Port already in use
SOLUTION: Change port - app.run(port=5001)

ISSUE: GIFs not loading
SOLUTION: Check internet connection (GIFs are external links)

ISSUE: Number guessing not working
SOLUTION: Ensure you're entering numbers only in the URL
